# bubak-tech
Responsive tech products store website built with HTML and Tailwind CSS (no JavaScript). Includes dark mode, product grid, and accessible navigation.
# BUBAK TECH

A modern, responsive tech products website built to practise Tailwind CSS.

## Features
- Responsive layout for mobile, tablet and desktop
- Sticky navbar with a no-JavaScript mobile menu
- Hero, featured categories, product grid, promo banner and About section
- Dark mode that follows the device setting
- Keyboard-friendly focus styles and lazy-loaded images

## Built With
- HTML5
- Tailwind CSS (Play CDN)
- Bootstrap Icons (icon font only)
